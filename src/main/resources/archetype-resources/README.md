**Project layout**

- `${package}.${pluginName}Plugin` - plugin entry point (`plugin-descriptor.properties` points at it).
- `src/main/plugin-metadata/plugin-descriptor.properties` - required ES plugin descriptor.
- `src/main/assemblies/plugin.xml` - builds the installable zip.
#if($pt == "rest")
- `${package}.rest.Rest${pluginName}Action` - example REST action, declares routes via `routes()`.
#end
- `src/test/java/.../${pluginName}PluginTests.java` - test scaffold.

**Build**

    mvn clean package

The installable plugin archive is written to `target/releases/`. Install it with:

    bin/elasticsearch-plugin install file:///absolute/path/to/target/releases/${artifactId}-${version}.zip

Restart the node afterwards. The plugin must be installed on every node of the cluster, and its `elasticsearch.version` must match the node version exactly (${elasticsearchVersion}).

**Try the REST API**

    curl 'http://localhost:9200/_${restName}?pretty'
    curl 'http://localhost:9200/my_index/_${restName}?pretty'

Routes are declared in `Rest${pluginName}Action.routes()` and the handler is registered from `${pluginName}Plugin.getRestHandlers(...)`. With Elasticsearch 7.x do **not** call `RestController.registerHandler()` from the constructor any more.
